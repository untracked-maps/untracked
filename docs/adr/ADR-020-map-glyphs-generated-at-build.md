# ADR-020 — Map glyphs generated at build time

**Date**: 2026-11-15
**Status**: accepted

## Context

MapLibre draws the labels of the map with glyphs: signed distance fields of a font's characters, in Protocol Buffers files of 256 code points each, which the style points to. They can come from the basemap provider, OpenFreeMap, or be served by the site. The previous app served the glyphs of Inter, the free font closest to the system fonts of phones, from files generated by a shell script with npm, Python's fontTools and Stadia Maps' `build_pbf_glyphs` in Rust, and committed into the repository. What can be generated is never committed here ([ADR-016](ADR-016-architecture-documentation-generated-and-published.md)).

## Decision

- The site serves its own glyphs of Inter, in its five weights the style uses (Regular, Medium, SemiBold, Bold, Italic), so that the basemap provider sees only tile requests.
- They are generated by a prerendered SvelteKit endpoint, `src/routes/glyphs/[fontstack]/[range].pbf/+server.ts`, which lists every stack and range in `entries()`: in development it renders a range on request, at build time SvelteKit writes the 1,280 files into `build/glyphs`. Nothing is committed; the site stays static.
- The work lives in `src/libraries/map-glyphs`, tested: Inter comes from the `inter-ui` package (SIL Open Font License 1.1) as WOFF2, `woff2-encoder` decompresses it to TrueType with Google's own decoder compiled to WebAssembly, and Mapbox's `fontnik` renders each range.
- `fontnik` ships prebuilt native binaries in its package, covered by the lockfile's integrity; its install script only checks that one is there, and is denied (`allowBuilds: fontnik: false`).
- These build-time dependencies are development dependencies. dependency-cruiser allows each in one place only: `fontnik`, `woff2-encoder` and `inter-ui` in `src/libraries/map-glyphs`, SvelteKit in prerendered endpoints, and Faker in in-memory adapters; any other development dependency there still fails. Biome allows Node.js modules in `src/libraries/map-glyphs` for the same reason.

## Consequences

- The build renders the glyphs on each run, in about 11 seconds for the whole build on 2026-11-15; they weigh 12 MB, as in the previous app.
- `fontnik`'s binaries cover Linux and macOS on x64 and arm64; another platform would compile it from source.

## Alternatives considered

- **OpenFreeMap's glyphs**: nothing to build, but every label request would reach the basemap provider too.
- **Committing the generated files**, as the previous app did: forbidden by ADR-016.
- **`@sakitam-gis/font-maker-cli`**: a single release, with no source repository declared.
- **`build_pbf_glyphs`**: last released in 2023, and a Rust toolchain next to Node.

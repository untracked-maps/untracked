# ADR-015 — AGPL-3.0

**Date**: 2026-11-15
**Status**: accepted

## Decision

The code is licensed under the GNU Affero General Public License version 3 only, as the previous project was. `LICENSE` holds the text published by the Free Software Foundation.

## Consequences

- Anyone who serves a modified version to users over a network must offer them its source.
- A dependency must have a licence compatible with the AGPL before it is added.
